This project uses Ansible vault to encrypt SSH-Keys, and decrypts them at run time

1. create + provision the Jenkins instance, locally, using TF from
Project-6/Jenkins-Pipeline_Terrafrom_Ansible_Wordpress/Terraform/layers/jenkins

The following command is used to invoke ansible playbook, in main.tf
>>  ansible-playbook -i jenkins-ci.ini \
../../../Ansible/jenkins/provision-jenkins.yml \
--vault-password-file=/Users/vija0326/Downloads/vault-pwd.txt



2. login to Jenkins create a pipeline job called "WP-pipeline" and use the below Jenkins file:
Project-6_1/Jenkins-Pipeline_Terrafrom_Ansible_Vault_Wordpress/Jenkins-Pipeline/jenkinsfile.groovy

use sparse checkouts
>> Project-6_1/Jenkins-Pipeline_Terrafrom_Ansible_Vault_Wordpress/Terraform/layers/wordpress
>> Project-6_1/Jenkins-Pipeline_Terrafrom_Ansible_Vault_Wordpress/Terraform/modules
>> Project-6_1/Jenkins-Pipeline_Terrafrom_Ansible_Vault_Wordpress/Ansible/wordpress-nginx
>> Project-6_1/Jenkins-Pipeline_Terrafrom_Ansible_Vault_Wordpress/Jenkins-Pipeline

The shell script which triggers Ansible to Provision WP also refers to the vault's PWD file
Jenkins-Pipeline_Terrafrom_Ansible_Vault_Wordpress/Ansible/wordpress-nginx/run.sh

ansible-playbook -i ./ec2.py site.yml --extra-vars jenkins_project_workspace=${jenk_proj_ws} --vault-password-file=/root/vault-pwd.txt
