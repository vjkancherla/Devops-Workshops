# DevOps Workshops

A progressive learning series of nine hands-on projects that combine the core
DevOps toolchain — **Ansible, Terraform, Jenkins, Packer, Vault, WordPress, and
observability stacks** — with each project building on the previous one.

## The projects

| Project | Toolchain |
|---|---|
| `Project-1` | Ansible |
| `Project-2` | Ansible + Terraform |
| `Project-3` | Ansible + Jenkins + Terraform |
| `Project-4` | Ansible + Jenkins + Terraform (with provisioners) |
| `Project-5` | Terraform + Jenkins + Ansible + WordPress |
| `Project-6` | Jenkins Pipeline + Terraform + Ansible + WordPress |
| `Project-6_1` | Jenkins Pipeline + Terraform + Ansible + **Vault** + WordPress |
| `Project-7` | Packer + Ansible + Terraform + Jenkins + WordPress |
| `Project-8` | Packer + Ansible + Terraform + Jenkins + WordPress + **Prometheus/Grafana/ELK** monitoring |

## What you'll learn

- Provisioning infrastructure with Terraform.
- Configuration management with Ansible.
- CI/CD automation with Jenkins (declarative pipelines).
- Image automation with Packer.
- Secrets management with Vault.
- Observability with Prometheus, Grafana, and ELK.

## Tools covered

- Ansible, Terraform, Jenkins, Packer, Vault, WordPress, Prometheus, Grafana, ELK.

## How to use

Work through the projects in order — each introduces one more tool on top of the
previous project. Read the `README.md`/notes in each folder before running it.
